# 业务需求文档

## 1. 项目背景

数据仓库当前包含5层数据模型：ODS、DWD、DWS、ADS。业务方计划对ODS层订单表进行字段调整，需要评估变更影响范围。

## 2. 业务目标

建立元数据血缘分析能力，实现以下目标：
- 自动解析ETL脚本中的表依赖关系
- 构建字段级别的数据流转链路
- 提供变更影响分析功能
- 输出可视化的血缘关系图

## 3. 功能需求

| 需求编号 | 需求描述 | 优先级 |
|----------|----------|--------|
| FR-01 | 解析SQL语句，提取源表和目标表 | P0 |
| FR-02 | 解析SQL语句，提取字段映射关系 | P1 |
| FR-03 | 构建表级血缘关系图 | P0 |
| FR-04 | 构建字段级血缘关系图 | P1 |
| FR-05 | 输入表名，输出所有下游依赖表 | P0 |
| FR-06 | 输入表名和字段名，输出字段级影响范围 | P1 |

## 4. 数据模型说明

| 表名 | 层级 | 说明 |
|------|------|------|
| ods_orders | ODS | 订单原始数据 |
| dwd_orders | DWD | 订单明细数据 |
| dws_customer_summary | DWS | 客户维度汇总 |
| dws_product_summary | DWS | 商品维度汇总 |
| ads_sales_report | ADS | 销售报表 |
